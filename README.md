# Super-ai-engineer-season-6
#  THackle DataViz Challenge: การวิเคราะห์และสร้างภาพข้อมูลเหตุความรุนแรงในครอบครัว (Domestic Violence in Thailand)

โปรเจกต์นี้เป็นการนำข้อมูลการแจ้งเหตุความรุนแรงในครอบครัวของประเทศไทย มาทำการวิเคราะห์และนำเสนอในรูปแบบ Data Visualization เพื่อค้นหา Insight ที่ซ่อนอยู่ และตอบคำถามสำคัญที่สามารถนำไปสู่การกำหนดนโยบายเพื่อป้องกันและแก้ไขปัญหาได้อย่างตรงจุด

##  ที่มาที่ไปของข้อมูล (Data Source)
ข้อมูลที่ใช้ในโปรเจกต์นี้เป็นส่วนหนึ่งของการแข่งขัน **THackle DataViz Challenge** ซึ่งรวบรวมสถิติการแจ้งเหตุความรุนแรงในครอบครัวจากหลากหลายช่องทางในประเทศไทย ข้อมูลดิบประกอบด้วย:
*   **แหล่งที่มาของการแจ้งเหตุ:** ระบบ VCIS (Victim Client Information System), ศูนย์ช่วยเหลือสังคม สายด่วน 1300 และช่องทางเอกสารจากหน่วยงานราชการ
*   **ข้อมูลเชิงพื้นที่และเวลา:** ภูมิภาค (Region), จังหวัด (Province), อำเภอ/เขต, ตำบล/แขวง และช่วงเวลาที่เกิดเหตุ (Period) เช่น 12:01 – 18:00
*   **ประเภทของสถานที่ (Locale):** เช่น สถานที่ส่วนบุคคล
*   **ปัจจัยและผู้เกี่ยวข้อง:** (เพิ่มรายละเอียดได้หากในชุดข้อมูลเต็มของคุณมีข้อมูลส่วนนี้ เช่น ช่วงอายุ เพศ หรือปัจจัยกระตุ้น)

## สิ่งที่อยู่ในโปรเจกต์นี้ (What's in the Code)
โปรเจกต์นี้เขียนด้วยภาษา **Python** โดยใช้ไลบรารีหลักอย่าง `pandas`, `matplotlib` และ `seaborn` เพื่อจัดการข้อมูลและสร้างกราฟ ภายใน Code ประกอบด้วยขั้นตอนการทำงานดังนี้:

1. **Data Preparation & Cleaning:**
   * การโหลดข้อมูลจากไฟล์ CSV https://www.thackle.or.th/th/dataset/84
   * การตรวจสอบความสมบูรณ์ของข้อมูล (Missing values, Data types)
   * การจัดกลุ่มข้อมูล (Data Grouping) เช่น การนับจำนวนเหตุการณ์ตามภูมิภาคและช่วงเวลา

2. **Data Visualization (การสร้างภาพข้อมูล):**
   โค้ดชุดนี้ได้สร้าง Visualization เพื่อตอบ 3 ประเด็นหลัก ได้แก่:
   * **Who is at risk? (ใครคือกลุ่มเสี่ยง):** การวิเคราะห์โครงสร้างของผู้กระทำและผู้ถูกกระทำ ผ่านกราฟเปรียบเทียบสัดส่วนเพศและช่วงอายุ (Population Pyramid / Bar Chart)
   * **Where & When? (เกิดที่ไหนและเมื่อไหร่):** การสร้าง **Heatmap (แผนที่ความร้อน)** เพื่อหาจุดวิกฤต (Hotspot) โดยเปรียบเทียบ "ภูมิภาค" กับ "ช่วงเวลาที่เกิดเหตุ" ซึ่งช่วยให้เห็นว่าพื้นที่ใดและเวลาใดมีการแจ้งเหตุหนาแน่นที่สุด
   * **What triggers violence? (อะไรคือปัจจัยกระตุ้น):** การนำเสนอสถิติปัจจัยเสี่ยง (เช่น แอลกอฮอล์, ยาเสพติด, ความเครียดทางเศรษฐกิจ) ผ่านกราฟแท่ง (Bar Chart) เพื่อจัดลำดับความสำคัญของสาเหตุ

3. **Exporting Assets:**
   * โค้ดมีการบันทึกผลลัพธ์ของกราฟออกมาเป็นไฟล์รูปภาพ (เช่น `hotspot_heatmap.png`) เพื่อนำไปใช้ประกอบการนำเสนอ (Data Storytelling)
