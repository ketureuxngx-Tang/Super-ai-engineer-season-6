# Domestic Violence Data Storytelling & Risk Analysis
**Super AI Engineer Season 6 - DataViz & Data Storytelling Challenge**

โปรเจกต์นี้เป็นการวิเคราะห์ข้อมูลเชิงลึก (Intensive Data Analysis) เกี่ยวกับสถิติการแจ้งเหตุความรุนแรงในครอบครัว เพื่อค้นหา Pattern ของความเสี่ยง จุดวิกฤต (Hotspots) และปัจจัยกระตุ้นหลัก โดยมีเป้าหมายเพื่อนำเสนอ **"ข้อเสนอแนะเชิงนโยบาย (Actionable Proposals)"** ที่หน่วยงานสามารถนำไปจัดสรรทรัพยากรและออกแบบมาตรการป้องกันได้อย่างตรงจุด

##  แนวทางการวิเคราะห์: ทำไมถึงเน้น Data Storytelling แทน Predictive Modeling?
จากการสำรวจและทดสอบข้อมูลเบื้องต้น พบว่าการสร้าง Machine Learning (Predictive Modeling) เพื่อแยกแยะ Target หรือทำนายพฤติกรรมความรุนแรงนั้น **ไม่สามารถทำได้อย่างมีประสิทธิภาพ (Low Data Separability)** เนื่องจากลักษณะของข้อมูลมีความทับซ้อนกันสูง นอกจากนี้ โมเดลทำนายผลยังไม่สามารถตอบโจทย์ทางธุรกิจ (Business Questions) หรือสร้าง Impact ในแง่ของการป้องกันเชิงนโยบายได้ดีพอ 

ด้วยเหตุนี้ โปรเจกต์นี้จึงมุ่งเน้นไปที่ **การวิเคราะห์ข้อมูลเชิงสำรวจแบบเข้มข้น (Intensive EDA & Data Storytelling)** ซึ่งให้คุณค่าทางธุรกิจ (Business Value) และ Insight ที่จับต้องได้มากกว่า นำไปสู่การตัดสินใจเชิงกลยุทธ์ที่สามารถใช้งานได้จริง

---

##  การทำความสะอาดข้อมูล (Data Cleaning)
เพื่อให้ได้ Insight ที่แม่นยำที่สุด ได้มีการเตรียมข้อมูลดังนี้:
1. **Duplicate Detection & Removal**: ลบข้อมูลที่ซ้ำซ้อน (Duplicates) ในทุก Dataset เพื่อป้องกันการนับเหตุการณ์เกินจริง (Double Counting) ซึ่งหลังจากการลบข้อมูลซ้ำ พบว่าจุด Peak ของอายุผู้กระทำผิดเปลี่ยนไป ทำให้ได้ Insight ที่แม่นยำขึ้น
2. **Noise Filtering**: กรองข้อมูลกลุ่มที่ไม่ระบุเพศออก (ซึ่งมีเพียง 0.16%) เพื่อลด Noise และให้เห็นโครงสร้างเปรียบเทียบระหว่างเพศชาย-หญิงได้อย่างชัดเจน

##  สรุปผลการวิเคราะห์และข้อเสนอแนะเชิงนโยบาย (Key Insights & Proposals)

###  ข้อ 1 — ใครเสี่ยงที่สุด? (Who is at risk?)
จากการเปรียบเทียบการกระจายตัวของอายุและเพศ ระหว่างผู้กระทำและผู้ถูกกระทำ พบโครงสร้างปัญหาที่น่าสนใจ:
* **The Age Gap (ความเหลื่อมล้ำทางวัย)**: ผู้ถูกกระทำมีจุดวิกฤตสูงสุด (Peak) ที่อายุเพียง **13 ปี** (เด็ก/เยาวชน) ในขณะที่ผู้กระทำมีจุด Peak ที่ **38-40 ปี** (วัยทำงาน) ช่องว่างระหว่างวัยที่ห่างกันถึง 27 ปีนี้ สะท้อนให้เห็นถึงปัญหาเชิงอำนาจระหว่างผู้ใหญ่และเด็กอย่างชัดเจน
* **Gender Pattern**: **เพศหญิง** ตกเป็นเหยื่อสูงกว่าเพศชายถึง **4 เท่า** (471 ราย vs 115 ราย) ในขณะที่เพศชายเป็นกลุ่มผู้กระทำความรุนแรงหลัก

*<img width="2380" height="981" alt="image" src="https://github.com/user-attachments/assets/b8a938e2-3475-47e1-8c06-0f9e12387a3e" />*

 **Actionable Proposal (ข้อเสนอแนะ)**:
* **มาตรการป้องกัน**: ควรมุ่งเน้นไปที่ระบบการเฝ้าระวังและการแจ้งเหตุใน **โรงเรียนมัธยมต้น** เนื่องจากเป็นจุด Peak ของผู้ถูกกระทำ และควรพัฒนาช่องทางการแจ้งเหตุแบบลับสำหรับผู้หญิงในชุมชน
* **กลุ่มเป้าหมาย**: ออกแบบแคมเปญรณรงค์ลดความรุนแรงในครอบครัว โดยมุ่งเป้าไปที่ "ผู้ชายวัยทำงาน (อายุ 30-45 ปี)" เพื่อปรับทัศนคติและสอนการจัดการอารมณ์

### ข้อ 2 — เกิดที่ไหน เมื่อไหร่? (Where & When?)
การสร้าง Heatmap เพื่อวิเคราะห์ความหนาแน่นเชิงพื้นที่และเวลา (Spatiotemporal Hotspots):
* **The Surprise Insight**: ข้อมูลชี้ให้เห็นว่าความรุนแรงในครอบครัว *ไม่ได้เกิดมากที่สุดในตอนกลางคืน* แต่กลับกระจุกตัวหนาแน่นใน **ช่วงเวลากลางวัน (06:01 - 18:00 น.)** ซึ่งคิดเป็นสัดส่วนมากกว่า **50%** ของเหตุการณ์ทั้งหมด (ช่วง 12:01-18:00 น. เกิดเหตุสูงสุดถึง 266 เคส)
* **Primary Location**: "สถานที่ส่วนบุคคล" (บ้าน/ที่พักอาศัย) ครองแชมป์อันดับ 1 อย่างโดดเดี่ยวในทุกช่วงเวลา

*<img width="1118" height="695" alt="image" src="https://github.com/user-attachments/assets/d8923590-dfac-4f65-a410-c52eca46e4fb" />*

 **Actionable Proposal (ข้อเสนอแนะ)**:
* **Daytime Resource Allocation**: จัดสรรและเพิ่มกำลังเจ้าหน้าที่รับแจ้งเหตุ รวมถึงทีมเคลื่อนที่เร็ว (Fast Response Team) ให้ครอบคลุม **ช่วงเวลาทำการ (08:00 - 18:00 น.)**
* **Home-Based Protection**: สร้างเครือข่ายเฝ้าระวังระดับชุมชน เช่น อสม. หรือเพื่อนบ้าน เพื่อช่วยสอดส่องดูแลบ้านพักอาศัยในช่วงเวลากลางวัน

###  ข้อ 3 — อะไรคือสัญญาณเตือน? (What triggers violence?)
การจัดอันดับปัจจัยเสี่ยง (Risk Factors) ที่กระตุ้นให้เกิดความรุนแรง:
* **The Top Triggers**: ปัจจัยเสี่ยงอันดับ 1 และ 2 คือ **"ยาเสพติด (Drug)"** และ **"สุรา (Alcohol)"** ซึ่งรวมกันเป็นปัจจัยกระตุ้นหลักในสัดส่วนที่สูงมาก (>60% ของเคสทั้งหมด)
* **Emotional Factors**: "การบันดาลโทสะ (Rage)" ตามมาเป็นอันดับ 3 (29.9%) ชี้ให้เห็นว่าความรุนแรงมักเกิดจากสารกระตุ้นร่วมกับสภาวะอารมณ์ที่ไม่มั่นคง โดยมีปัญหาเศรษฐกิจ (Economics Stress) เป็นตัวเร่ง

*<img width="1336" height="881" alt="image" src="https://github.com/user-attachments/assets/03fd18b1-36be-4787-a7d2-7e7b1a0bd011" />*
  
 **Actionable Proposal (ข้อเสนอแนะ)**:
* **Primary Prevention (การตัดวงจร)**: รัฐควรออกแบบมาตรการบำบัดผู้ติดสารเสพติดและสุราในชุมชนอย่างจริงจัง เนื่องจากเป็นจุดเริ่มต้น (Root Cause) ของปัญหา
* **Early Warning**: หากพบครอบครัวที่มีสัญญาณของปัญหาเศรษฐกิจและเริ่มมีการใช้สุรา/ยาเสพติด หน่วยงานที่เกี่ยวข้องควรเข้าไปแทรกแซง (Intervene) ทันที ก่อนที่ปัญหาจะบานปลายไปสู่ความรุนแรงทางร่างกาย
